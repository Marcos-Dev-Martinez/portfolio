01 — Sobre mí

Quién soy

Soy Marcos Martínez, desarrollador web de Valencia. Aprendí de forma autodidacta y tengo cinco proyectos publicados y en funcionamiento, construidos desde cero. En 2026 empiezo el ciclo formativo de Sistemas Microinformáticos y Redes (SMR) para reforzar la base de sistemas y redes, y estoy cursando la certificación de FreeCodeCamp en Desarrollo Web.

Me especializo en maquetación HTML semántica, CSS moderno y JavaScript para crear interfaces funcionales y accesibles. Disfruto construir desde la estructura hasta la lógica de interacción.

Todos mis proyectos cumplen con la normativa europea de accesibilidad web (WCAG 2.1) y el Reglamento General de Protección de Datos (RGPD), ya que creo que la web debe ser abierta e inclusiva para todos.

⚖️ Cumplimiento normativa europea

Mis proyectos siguen las directrices WCAG 2.1 nivel AA (Directiva UE 2016/2102), el RGPD (Reglamento UE 2016/679) para el tratamiento de datos personales, y la Directiva de servicios de la sociedad de la información (LSSI).
